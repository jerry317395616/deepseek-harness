# Agent Note: 一个 Harness 进程内的账号所属会话

Status: implemented

[English](2026-09-07-shared-session-ownership.md) | 中文

## 问题

用户要求共享一个 Harness，而不是每名员工一个进程。Host 启动 Cookie 不是 Frappe 主体，已有只读代理的 UID 绑定也不能区分共享进程内的调用者。所有员工共用任一种凭据都会消除其授权边界。

## 决策

使用明确限定账号归属的 API 预览：可信 Unix 套接字身份服务验证签名交接票据与当前启用账号，Session Controller 子路径在模型日志之外分配不可变的 `{site,user}` 归属。创建在成功返回前持久化该会话；列表、分页及限定范围的读取核验归属，并在返回数据前复查登录。缺少归属、输入错误及身份服务失败均拒绝访问。

员工凭据仅授权此 API。普通 Host API 和全局事件流保留 Host 认证。可选[请求所属轮次](2026-09-07-employee-authenticated-turns.zh.md)在只读执行中保留已验证调用者；省略预设时继续阻止执行。账号启用检查不能代替 Frappe 业务权限。

对于读取请求，身份服务根据解析后的登录选择已有固定账号配置，再复用原生读取程序的签名身份与 ORM 权限检查。共享 UID 只允许运行时进程接入，不选择员工身份。明确范围、严格参数、每账号最多一个进行中的读取以及有上限的响应共同约束此 API。读取后的登录复查防止退出、停用或过期时返回进行中请求的结果；替换登录不能恢复旧请求。

## 考虑过的替代方案

**使用 Host 提示执行员工会话。** Host 认证不会将 Frappe 账号绑定到排队任务。所属执行需要请求拥有的认证轮次；否则拒绝步骤、请求和工具调用。归属在创建会话前加入索引，在准入前恢复；失败的预留仍被阻止。独立角色记录使用无员工归属的 Host 会话，共享记录使用员工 API。

**共享管理员执行，并在提示中写入角色文字。** 模型指令不能强制执行文档、字段或流程权限。调用身份必须来自认证，并在执行中保持固定。

**一次修改全部远程 API 与界面。** 这会在逐调用身份桥接完成前开放执行。限定接口的预览允许通过双账号测试发现隔离缺陷，无需发布不完整的员工入口。

**为会话归属重命名或新增 Frappe DocType。** 项目禁止结构变更。私有的追加式归属记录无需触碰应用结构或业务记录即可支持重启恢复。

## 影响

针对性 HTTP 与归属测试覆盖双账号、伪造归属、无归属旧会话、不可变文件、响应上限、超时、客户端断开及销毁。Python 测试覆盖重放竞态、复查中退出、账号停用、过期、重启及真实套接字回收。真实进程夹具将两个账号接入同一个 Web 进程；已有会话回放在不改变模型可见契约的情况下验证所属历史。

[指南](../../../../docs/user/guide/employee-shared.zh.md)定义配置和验收边界。读取测试覆盖双账号并发、身份伪造、范围拒绝、读取中撤销、取消及共享运行时重启。夹具中的业务结果是合成数据；原生适配器复用已有签名读取测试，不代表线上站点验收。共享员工界面、正式单点登录路由及浏览器、线上站点和负载验收仍待完成。正式路由、服务、Frappe 账号、记录和 DocType 均未改变。
